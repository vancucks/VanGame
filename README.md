# Pega-Ladrão

1. Crie um projeto no Firebase.
2. Em Authentication, ative o método **Anônimo**.
3. Crie o Firestore em modo de produção.
4. Cole o conteúdo de `firestore.rules` nas Regras do Firestore e publique.
5. Registre um app Web e copie as chaves para um arquivo `.env` (copiado de `.env.example`).
6. Execute `npm install`.
7. Execute `npx expo start`.
8. Abra no celular com o app Expo Go (Android e iOS) escaneando o QR code.

No iOS, deixe o app aberto na tela durante a partida; não há GPS em segundo plano.
